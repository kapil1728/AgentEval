# Code of Conduct

## Our commitment

AgentEval is intended to be a welcoming, respectful, and constructive project for everyone, regardless of background or identity.

## Expected behavior

- Be considerate, respectful, and constructive.
- Focus feedback on ideas and work, not on people.
- Accept responsibility, learn from mistakes, and help resolve disagreements respectfully.
- Respect privacy; do not publish another person's personal information without permission.

## Unacceptable behavior

Harassment, discrimination, personal attacks, intimidation, sexualized language or imagery, and publishing private information without consent are not acceptable.

## Enforcement

Project maintainers may edit or remove contributions that violate this code and may restrict participation when needed to protect the community. Report concerns privately to [Kapil.Krishnan@gmail.com](mailto:Kapil.Krishnan@gmail.com). For security issues, follow [SECURITY.md](SECURITY.md) instead.
